# Midstream Gathering & Processing Deduction Audit

Audit midstream volume loss, fuel, shrink, processing fees, NGL yields, and netback settlement calculations.

**Primary buyer:** Producers and mineral owners. **Evidence:** gathering and processing agreements, meter volumes, quality, shrink, fuel, NGL yields, residue gas, fees, index prices, statements, and cash.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Midstream contract library
- Meter statement ingestion
- Volume balancing
- Gas quality adjustment
- Fuel use calculation
- Shrink calculation
- Processing fee validation
- NGL yield calculation
- NGL price validation
- Residue gas settlement
- Gathering fee audit
- Netback reconstruction
- Midstream dispute workflow
- Cash reconciliation
- System plant analytics
